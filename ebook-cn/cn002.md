## 2.1 核心定义：三大支柱

Archi 在企业架构（EA）工具市场中凭借三个核心特性脱颖而出：

1. **开源（Open Source）**： 核心代码透明，允许极高的定制化和灵活性。

2. **跨平台（Cross-Platform）**： 完美支持 Windows, macOS 和 Linux 系统。

3. **专注 ArchiMate**： 专门为 ArchiMate 建模语言设计，与 Open Group 的最新标准保持同步。

## 2.2 目标受众与角色化建模

Archi 不仅仅是为“企业架构师”设计的，它支持架构团队中的所有专业角色：

- **业务架构师（Business Architects）**： 建模价值流、业务能力和业务流程。

- **应用/解决方案架构师（Application/Solution Architects）**： 绘制应用组件关联和数据流向。

- **技术/基础设施架构师（Technology Architects）**： 可视化节点、网络和系统部署。

- **集成/信息架构师**： 定义跨层级的数据流转。

## 2.3 工具版图：Archi 与商业工具的对比

Open Group 维护着一份认证的 ArchiMate 工具清单。虽然 Archi 未参与商业认证，但在兼容性上表现卓越：

- **商业巨头**： 如 BizzDesign, Sparx Systems (EA) 和 Visual Paradigm。它们功能极其强大，但授权费用昂贵。

- **开源竞品**： 如 Modelio。这类工具通常覆盖范围较广（UML, BPMN），而 Archi 全力专注于 ArchiMate，为 EA 建模提供了更纯粹、简洁的体验。

- **“纯净”优势**： 许多商业工具会引入私有的元数据（Metadata），而 Archi 保持了语言的纯洁性，确保你的模型完全符合标准且易于迁移。

## 2.4 Archi 生态系统与社区力量

Archi 的生命力源于其活跃的开发与支持网络：

- **Archi 论坛**： 极其活跃，主开发者经常实时回复 Bug 报告和功能建议。

- **GitHub 项目**： 核心代码和关键插件（如 Git 协作插件/co-modeling）均已开源。目前版本 2 协作插件正在测试中，将进一步提升团队协作体验。

- **ArchiMate 101**： 强烈建议在学习工具的同时，参考 ArchiMate 3.2 规范。工具是语言的实现，深入理解语言逻辑将使建模事半功倍。
